# 🌾 Maa Shakti SHG - Tamper-Evident Digital Ledger

A low-literacy-first, tamper-evident financial ledger built for Self-Help Groups (SHGs) and federations (NRLM/DAY).

## 💡 Key Features
- **Cryptographic Hash Chain:** Private SHA-256 block linking makes retroactive book edits immediately detectable.
- **Dual-Party Entry Verification:** Member 4-digit PIN confirmation stops corrupt bookkeepers from entering fraudulent data.
- **Audio Soundbox Feedback:** Real-time regional voice confirmations announce transactions during group meetings.
- **Federation Remote Audit:** One-click automated integrity checks and standardized NRLM audit reporting.
